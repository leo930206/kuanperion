# Kuan Hypixel SkyBlock Assistant

Minecraft **26.2** 的 Fabric 客戶端輔助模組，提供 Mining、Farming 與通知功能。

**版本：`1.0.128`**

## 安裝與更新

1. 使用 Minecraft 26.2 的 Fabric instance，並安裝 Fabric API。
2. 將最新版 `kuan-hypixel-skyblock-assistant-版本號.jar` 放入該 instance 的 `mods` 資料夾。
3. 移除本模組的舊版 jar，保留其他 mod，然後完整重啟 Minecraft。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `'` | 開啟設定 |
| `Shift + M` | 開啟／關閉 Mining |
| `Shift + F` | 開啟／關閉 Farming |

Mining 與 Farming 無法同時開啟。重新啟動遊戲後，需手動啟用。

## Mining

1. 開啟設定，點選「選擇目標方塊」，輸入種類數量（1～5）。
2. 依提示對準方塊按右鍵，選滿指定種類。
3. 使用 `↑`、`↓` 排列優先順序，`×` 可刪除目標。
4. 視需要調整偵測半徑、轉動速度與挖礦延遲，再啟用 Mining。

啟用期間會鎖定手動移動、視角與左鍵；要恢復一般操作，請先關閉 Mining。

## Farming

1. 使用相容的農場配置，站在起始位置並手持對應農具。
2. 將準星對準作物，按 `Shift + F` 啟用；再次按下即可停止。
3. 可依需求開關「工具偵測」、「智慧暫停」與「異常狀況處理」。

農場標記：黃色染色玻璃為換列、淺藍色染色玻璃為起點、粉紅色染色玻璃為終點。

開啟工具偵測時，拿錯工具會暫停，換回正確工具後繼續。智慧暫停可在開啟背包、聊天室等介面時暫停操作。

> 農場布局需與作物相容。首次使用請先在可監看遊戲的情況下測試。

## Visitor／Pest 通知

1. 點選 Farming 區的「Visitor 通知」或「Pest 通知」啟用並進入設定。
2. 門檻沿用上次設定；需要修改時，點選第一行。Visitor 可設定 1～5，Pest 可設定 1～8。
3. 選擇想使用的通知方式，按「完成」返回。

要關閉通知，再點一次外層已開啟的按鈕。想重新調整設定，可關閉後再開啟。

## Jerry 偵測

在 Other 區點選「Jerry 偵測」：

- 選擇 Green／Blue／Purple／Golden，只通知已開啟的顏色。
- 開啟「出現 Jerry 是否停下動作」後，選定顏色的 Jerry 出現時會停止 Mining／Farming。
- 通知會顯示實際種類，例如「發現 Golden Jerry！」。

## 通知方式

各功能可獨立設定，三種方式可同時使用：

| 選項 | 使用方式 |
| --- | --- |
| Discord 訊息通知 | 開啟後輸入 Webhook URL |
| 遊戲內聊天室通知 | 在本機聊天室顯示提醒 |
| 遊戲內螢幕通知 | 在畫面中央顯示提醒；開啟時輸入顯示秒數 |

- 三個功能共用 Webhook URL，但 Discord 開關各自獨立。請勿公開 Webhook。
- 螢幕顯示秒數各自保存，可輸入正整數或小數，例如 `6`、`0.5`、`1.25`。
- 修改 Webhook 或顯示秒數時，先將該通知方式關閉再開啟。
