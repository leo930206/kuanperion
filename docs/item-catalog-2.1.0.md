# Public item catalog — 2.1.0 development

Visitor/Supercraft must not guess an item ID from a GUI button or a fuzzy display name. The shared read-only catalog accepts only the official resource schema, valid exact IDs and unique names after legacy-format removal. Duplicate IDs/JSON keys, malformed UTF8/numeric/schema values, excessive bytes/depth/tokens/strings/collections are denied. Ambiguous names (including formatting collisions) are omitted entirely rather than choosing first/last; no substring, case-fold, remote name service or author backend fallback exists.

The fixed HTTPS public Hypixel resource-items client is anonymous and demand-only: no query parameters, credentials, player identifiers, configuration uploads, telemetry, cookies or custom device headers. It uses the existing redirect-denying HTTP factory and bounded streaming subscriber. Each explicit request has8s HTTP/10s future bounds; concurrent demand coalesces, errors back off60s, results cache24h from receipt time, and close cancels the real HTTP stream. An unchanged old resource timestamp does not mean a newly downloaded catalog is stale. Clock reversal invalidates cache/backoff. No background timer or startup request is added.

This slice supplies a dependency, not permission to act. No native/legacy consumer constructs or fetches it yet; future approved Visitor/Supercraft services must own lifecycle/close, check freshness/world/session on completion, match exact material allowlists and independently validate live GUI costs/quantities. A catalog/price estimate is never purchase, consumption or movement authority. Unknown data fails closed.

Pure tests use fake transport only. A previously downloaded official items snapshot (2026-10-24, SHA256 adb76eae35cbce2f18f01b947f9d914967b36e53895adf615e39efbd9d2c4fe8) was parsed locally:5680 items ->5364 unambiguous names, including exact Enchanted Wheat mapping. The full4.8MB source is not bundled; no live API request, account or game-server interaction was made during this slice.
