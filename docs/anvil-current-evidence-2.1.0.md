## 此檢查點採用的邊界

- 固定 `/anvil` typed sender；不接受設定或聊天帶入任意指令、沒有 `/av` fallback。
- Trade 的 Book Combine 設定／service／原生 port 已接線，預設關閉且附魔 ID／最高等級授權為空；每次只處理一組受保護檢查通過的同級、同 metadata 單附魔書。設定保存在既有外部 automation.json，非 JAR。
- 候選結果僅限已知預覽／合成角色13／22，不宣稱截圖證明按下之後物品在哪。只有兩個輸入均有新的消耗回條，且其中唯一一個候選格具有新的精確預期結果／游標證據時，才進入指定主背包格取回；兩格都有結果或只有舊預覽不會收取。直接入背包仍須完整精確增量與新伺服器回條。
- `freeCombine()` 仍只接受明確單一 `Cost: 0 Exp Levels` 或 `Cost: 0 Experience Levels` 及精確點擊提示；正值、重複、缺失、額外未知費用均拒絕。不代表目前伺服器真的採此文案；現有截圖本身會被費用守門拒絕。
- 停止、Jerry、手動指令／視角／背包、世界／死亡／斷線／Mining 等優先撤銷；不自動修游標、重播不確定點擊或關玩家已接手選單。只在明確成功後釋放原 Farming hold，不能自動重開 Farming。

## 尚待確認

目前書＋書的真實費用文案、按下之後的實際物品／容器回覆、不同帳號開啟權限與實際連服成功，仍需驗證。若當前格式不是明確零費用，現有開發入口會安全拒絕，不應把它稱為完整線上可用或透過放寬費用檢查冒充完成。正式2.0.17／設定／mods 不動。

完整回歸、固定26.2原生 API 建置／成品稽核、實際 Book task/controller 配模擬伺服器回條、原生物品／Slot fixtures、8組使用正式編譯類別的 Book 模型、Trade UI 實際設定綁定／待執行取消及設定遷移均通過。補上包含 Book 的8個 gameplay root 設定門禁檢查；9個服務（另含 Stash）的 Jerry／生命周期停止矩陣已涵蓋 Book。測試要求空快捷列不被填入、結果13須新回條、雙候選拒絕、原書取回後舊預覽仍不得關閉，以及滿背包例外不掩蓋其他 blocker。

這些是離線模型、實際方法本體與原生類別 fixture 證明，不是本輪 GUI／Mixin 啟動、伺服器合書成功、零費用當前格式或完整2.1.0驗收。正式安裝與設定保持不動。
